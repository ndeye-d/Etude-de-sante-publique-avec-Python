# 📊Etude de santé publique avec Python
## 🎯Objectif
La [Food and Agriculture Organization of the United Nations (FAO)](https://www.fao.org/home/en/) est un organe de l'O.N.U. dont l'objectif est d'atteindre la sécurité alimentaire dans le monde.
Dans le cadre de ce projet, j'ai réalisé une étude de l'alimentation et de la sous-nutrition dans le monde entre 2013 et 2017 à partir des données fournies par la FAO.
Voici les fichiers fournit par la FAO:
- **Population** qui contient les populations par pays de 2013 à 2018
- **Disponibilité alimentaire** qui contient les disponibilités alimentaires, les utilisations des produits alimentaires, l’origine animale ou végétale des produits alimentaires par pays
- **Aide alimentaire** qui contient la quantité d'aide alimentaire accordée par pays de 2013 à 2016
- **Sous-nutrition** qui contient le nombre d’habitant en sous-nutrition par pays de 2013 à 2018
## 🛠️Outils
- Python
  - **Pandas** : Analyse et exploration des données
  - **Seaborn**, **Plotly** et **Matplotlib** : Visualisation des données
## 🚀Résultats
Les pays en développement reçoivent le plus d'aide alimentaire
